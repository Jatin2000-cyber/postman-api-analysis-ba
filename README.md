# E-Commerce API Analysis (Business Analyst Mini Project)

## Objective
Analyze a REST API using Postman from a Business Analyst's perspective, and turn observed behavior into requirements.

## API Used
DummyJSON (https://dummyjson.com), a free public API

## What I Did
- Built a Postman collection covering authentication, CRUD operations and negative scenarios
- Used environments and variables to manage the base URL and token
- Documented endpoints, request/response fields and status codes
- Wrote user stories with Given/When/Then acceptance criteria
- Performed a gap analysis against business needs

## Contents
- `postman/`: exported collection and environment
- `docs/`: API analysis table, user stories, gap analysis, flow diagram
- `screenshots/`: sample requests and responses
